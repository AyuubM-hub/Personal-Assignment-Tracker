# Student Assignment & Deadline Tracker  

A Java and PostgreSQL application designed to help students organise university assignments, manage deadlines and monitor completion status.  
  

## Technologies Used  
- Java 21  
- PostgreSQL 14  
- JDBC  
- Visual Studio Code  
  

## Planned Features  
- Add assignments  
- View assignments  
- Organise assignments by module  
- Edit and delete assignments    
  

## Database  
The application uses PostgreSQL to store assignment and module information.  
  

Database name: `assignment_tracker`  
  

## Project Status  
Fully complete. You can add, delete and update assignments.
